# The Zen of Canary

The Zen of Canary captures the guiding principles for Canary language design. Every language feature, syntax decision, and design choice must follow them.

When in doubt, refer back to these principles. If a feature contradicts them, the feature is wrong, not the principles.

```text
Clarity over cleverness.
Hide the tedium; surface the hazard.
There should be one obvious way to do it.
Speak intent, not plumbing.
Better the canary sing at compile time than the mine fall at run time.
```
